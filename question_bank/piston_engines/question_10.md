# Question 10 — Lycoming O-360 air-standard and brake performance

- Source: [Problem set Q8](../../problem_sets/MAE3405%20Problem%20Set%20Questions%20-%20Week%203-4.pdf#page=2), PDF page 2.

A 4-cylinder Lycoming O-360 engine operates on aviation gasoline at SSL with the following specifications:

| Quantity | Value |
|---|---:|
| Operating cycle | Four-stroke |
| Cylinders | 4 |
| Total swept volume | 5.90 L |
| Compression ratio | 8.5 |
| Take-off brake power | 134 kW |
| Take-off speed | 2700 RPM |
| 65% cruise brake power | 87.1 kW |
| Cruise speed | 2400 RPM |
| Take-off volumetric efficiency, ambient-air referenced | 85% |
| Air/fuel mass ratio | 14.7 |

Determine:

(i) the air-standard thermal efficiency;

(ii) the valve clearance space per cylinder;

(iii) the BMEP for take-off and the 65% cruise condition; and

(iv) the brake thermal efficiency at take-off, assuming an air to fuel ratio of 14.7 and volumetric efficiency of 85%.
